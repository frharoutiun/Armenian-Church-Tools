Search

Armenian search matches every case/number ending of a word's dictionary root, not just the exact spelling typed — e.g. searching one form of "God" finds every form of it across the corpus. English search currently only covers the one section that has been fully translated so far; more will appear as translation continues.

About this tool

Armenian text is the corrected-spelling (dictionary-form) pass of the cleaned Krapar corpus. The "Ganon" heading label follows the parish's own Maroon Book transliteration convention (via TR), not a literal letter-by-letter transliteration. Root/declension search is powered by uniparser-classical-armenian, a rule-based morphological analyzer for literary Classical Armenian.

Please send any feedback regarding accuracy or functionality to Fr. Haroutiun Sabounjian at frharoutiun@gmail.com.
